# 🧠 Dynamic Customer Segmentation using PySpark

## 📌 Overview

Scalable customer segmentation and behavior prediction using **PySpark, HDFS, and RFM analysis** on large-scale retail data.

---

## ⚙️ Tech Stack

* PySpark, Hadoop (HDFS)
* K-Means Clustering
* Gradient Boosted Trees (GBT)
* Python, MLlib

---

## 🧪 Approach

* Cleaned and processed ~541K transactions
* Engineered **RFM features (Recency, Frequency, Monetary)**
* Applied **K-Means (k=4)** for segmentation
* Built **GBT model** for predicting customer behavior

---

## 📊 Results

* **Silhouette Score:** 0.75
* **Accuracy:** 91.3%
* Identified key segments:

  * Active Customers
  * Dormant Users
  * High-Value Customers
  * Elite Spenders

---

## 💡 Impact

* Enables targeted marketing & churn prediction
* Demonstrates scalable big data ML pipeline
